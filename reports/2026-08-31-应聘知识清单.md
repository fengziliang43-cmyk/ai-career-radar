# AI 新职业雷达：应聘知识清单

> 核对日期：2026-08-31  
> 适用范围：[[2026-08-29-第1期-v2-前沿修正版|第 1 期 v2]] 的 13 个职业 / 任务簇  
> 口径：从当前代表性雇主岗位归纳常见知识，用于准备与自查，不代表所有雇主的统一硬门槛。

本清单只回答“需要懂什么”。学历、工作年限、作品、证书、沟通能力和行业经历仍需按具体 JD 单独核对，不能混写成知识要求。职业证据、市场层级和来源仍以 [[2026-08-29-第1期-v2-前沿修正版|第 1 期 v2]]、[[../sources/registry|信源登记]]和站内各职业的主要来源为准。

## 1. FDE / AI Deployment Engineer

- **生产级软件工程**：Python、JavaScript / TypeScript、前后端 API、SQL、Git、测试与调试，以及云服务、容器、日志和可观测性基础。
- **LLM 与 Agent 系统**：上下文、结构化输出、工具调用、RAG、Agent 编排、评测与护栏，并能权衡效果、延迟、成本和可靠性。
- **企业集成与交付**：需求发现、技术范围界定、系统架构、数据与权限对接，以及从 PoC、上线、采用到交接的完整流程。
- **领域、安全与合规**：理解客户业务流程、数据隐私、授权、审计和风险控制；医疗方向还需了解 EHR、HL7 / FHIR 与受监管交付。

## 2. AI Product Engineer / AI 产品工程师

- **全栈开发基础**：HTML / CSS、JavaScript / TypeScript、React 或同类框架、API、数据库、身份认证，以及独立调试、测试和部署。
- **AI 应用模式**：模型 API、Prompt、上下文、RAG、结构化输出、工具调用、Agent 工作流和基础评测。
- **产品与交互**：用户问题识别、需求拆解、原型、交互细节、产品指标和快速迭代，能判断什么值得做而不只是把功能写出来。
- **AI Coding 工程纪律**：熟悉 Cursor、Codex 或 Claude Code 等工作流，同时掌握版本控制、代码审查、错误定位、安全与质量验证。

## 3. Agent Evals Product / Agent 策略 PM

- **Agent 运行机制**：规划、记忆、工具调用、Skill、多步任务、上下文管理、轨迹记录和人工接管的基本机制。
- **长程任务评测**：测试集、Rubric、完成率、记忆连贯性、成本、延迟、异常恢复与失败归因，能把模糊体验变成可测指标。
- **策略与产品方法**：需求拆解、Skill 功能逻辑与调用策略、方案文档、优先级、上线复盘，以及算法、工程、测试间的协作流程。
- **数据分析基础**：表格、SQL 或 Python 的基础分析，理解抽样、对照实验、趋势与负样本分类，并能输出可执行的评测报告。

## 4. Agent Evaluation Engineer / Environment Builder

- **Python 与评测工程**：Python、API、JSON / JSONL、Git、自动化测试、数据处理和可视化，能搭建可重复运行的评测脚本或框架。
- **评测方法**：Benchmark、消融实验、人工评测、LLM-as-a-judge、环境反馈、评分校准和评测者一致性。
- **Agent 环境与轨迹**：记忆、规划、工具调用、反思、模拟环境、沙箱、轨迹日志、失败重放和自动 Grader。
- **统计与误差分析**：抽样、置信区间、显著性、分层对比、错误分类和回归测试，能从行为日志定位系统瓶颈。

## 5. Agent Post-Training Engineer / Researcher

- **机器学习基础**：概率统计、线性代数、优化、深度学习、Transformer、Tokenization、损失函数和模型推理。
- **后训练方法**：SFT、偏好数据、奖励模型、RLHF、DPO、GRPO、强化学习与数据配比，理解各方法解决什么行为问题。
- **Agent 训练信号**：任务环境、Rollout、Grader、工具使用、长上下文、失败轨迹，以及离线评测与在线行为之间的关系。
- **训练系统与研究**：Python、PyTorch 或 JAX、GPU / 分布式训练、数据流水线、实验设计、消融、复现和结果解释。

## 6. Applied AI Architect / Applied AI Engineer

- **企业技术架构**：云、网络、IAM、API、事件与数据系统、可观测性、SLA、安全边界和高可用基础。
- **生成式 AI 方案设计**：模型选择、Prompt、RAG、微调、工具调用、Agent、评测、护栏，以及质量、成本和延迟权衡。
- **集成与生产化**：现状调研、数据分类、遗留系统集成、PoC、上线标准、监控、回滚和组织采用流程。
- **咨询与领域表达**：把业务目标转成技术方案和非功能要求，能写架构文档，并向管理者、工程师、法务和领域专家解释取舍。

## 7. AI Success Engineer / 领域 AI 成功工程师

- **AI 产品基础**：模型能力与限制、Prompt、RAG、Agent、评测、隐私和安全，能判断客户问题是否适合用 AI 解决。
- **集成与排障**：API / SDK、身份认证、连接器、日志和问题复现基础，能与客户工程团队定位接入与效果问题。
- **采用与变革管理**：用例筛选、工作流重构、培训、上线辅导、反馈闭环和组织推动，而不只是回答产品怎么用。
- **领域与成功指标**：理解目标行业流程与合规边界，并会定义激活、采用、任务结果、质量、成本和节省时间等指标。

## 8. Agentic Risk / Safeguards Analyst

- **Agent 架构与失效模式**：目标、规划、记忆、检索、连接器、Computer Use、多 Agent 协作，以及自治系统如何产生意外行为。
- **安全与滥用分析**：Prompt Injection、越权、数据外泄、欺诈与社会工程、红队、评测、事件调查和威胁建模。
- **风险治理**：风险分类、严重度、证据与置信度、责任人、缓解措施、剩余风险、发布准备度和升级机制。
- **情报与分析工具**：弱信号、假设检验、多源证据综合，以及 SQL、Python、仪表盘和面向决策者的简洁风险报告。

## 9. Agent Identity & Trust Designer

- **身份与访问控制**：认证与授权、MFA、账户恢复、会话与设备、RBAC / ABAC、OAuth / OIDC 和最小权限原则。
- **Agent 委托与信任**：Agent 代表谁、授权范围、凭证生命周期、人—Agent 与 Agent—Agent 信任、审计和可追责性。
- **安全体验设计**：权限说明、知情同意、敏感动作确认、风险提示、错误恢复和人工接管，在安全与低摩擦之间取舍。
- **复杂产品设计**：信息架构、交互设计、原型、可用性测试、无障碍、企业管理后台和跨产品设计系统。

## 10. Agent Product Manager / Workflow Product

- **Agent 技术基础**：模型与上下文、RAG、记忆、工具与连接器、编排、多 Agent 协作，以及各能力的边界。
- **工作流产品设计**：任务拆解、模型与工具分工、状态管理、重试、降级、人工接管、权限和异常恢复。
- **Agent 评测指标**：任务成功率、人工介入率、完成时间、成本、延迟、质量、安全和基于轨迹的失败归因。
- **技术产品方法**：API / SDK、JSON、日志和 SQL 基础，以及用户研究、PRD、路线图、实验、发布和跨团队推进。

## 11. 医疗 AI 评测与领域数据质量

- **临床与循证医学**：临床理论、诊疗思维、鉴别诊断、指南与专家共识、中英文文献检索，以及证据等级与适用边界。
- **模型评测方法**：Benchmark、Rubric、金标准、人工与自动评测、LLM-as-a-judge、错误归因和多模型多版本回归。
- **医学统计与测量**：敏感度、特异度、Precision、Recall、F1、AUC、校准、Cohen’s Kappa、置信区间、显著性和偏倚。
- **医学数据质量**：标注规范、样本筛选、数据来源、质检、医学风险分类，以及问答、报告解读、用药、多模态和 RAG 场景。
- **隐私、合规与临床安全**：去标识化、患者隐私、人工复核、高风险升级、适用范围、审计证据和医疗产品上线验收边界。

## 12. 通用 AI 产品运营 / RAG 知识治理

- **RAG 工作原理**：文档切分、Embedding、向量索引、混合检索、Rerank、上下文组装、引用和常见幻觉来源。
- **知识治理**：信源权威性、元数据、分类体系、版本与时效、去重、权限、审计和内容更新流程。
- **效果评估**：检索召回、答案忠实度、覆盖率、黄金问题集、人工质检、A/B 测试和版本回归。
- **运营与数据基础**：API、SQL、表格、日志与监控基础，以及客户接入、文档、反馈分析和问题闭环。

## 13. 独立提示词 / 泛训练师 / 模板数字人

- **模型行为基础**：上下文、指令层级、采样、结构化输出、工具调用、模型边界和常见失败，不能只会堆提示词模板。
- **Prompt 与评测工程**：模板与版本管理、测试集、Rubric、A/B 对照和回归评测，用数据证明改动而不是凭单个案例。
- **数据与内容质量**：标注规范、抽检、版权、隐私和事实核验；数字人方向还要懂 ASR / TTS、脚本、音视频和口型链路。
- **领域与产品结果**：必须叠加某个行业知识、业务流程、用户指标或自动化交付能力，否则独立头衔很容易被其他岗位吸收。
