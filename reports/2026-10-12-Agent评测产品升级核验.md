## 事实

- 美团 3 个、腾讯 2 个岗位以 Agent 评测或 Agent 策略为主要职责，分属美团核心本地商业的基础研发平台、业务研发平台，以及腾讯 CSIG、TEG。
- 职责结构一致：从真实场景定义任务和评分标准（Rubric），自动化评测（含 LLM-as-Judge），从执行轨迹做失败归因，再把结果转成模型与策略优化。
- 门槛：美团 CatPaw 岗和平台岗要求 3 年以上（CatPaw 岗含 1 年以上大模型或 Agent 产品经验）；LongCat 岗要求 1 年以上大模型评测或智能体落地经验，并写明欢迎算法、工程转岗；腾讯接口不含任职要求。9 个岗位里没有实习或应届入口。
- 网站的 17 个海外来源里没有「Agent 评测产品经理」同名岗位。最接近的是 Cohere 的 Product Manager, Agent Harness & Modelling；评测在海外多由工程岗承担，例如 Glean 的 Software Engineer, Evals。

## 推断

- Agent 评测产品正在成为自研大模型平台的固定分工：Agent 产品线越多，越需要专人定义「真实场景下稳定完成」的标准，并把失败归因到具体环节。
- 职位名尚未统一（评测产品经理、Harness 策略产品经理、数据策略分析），但任务结构已经稳定，正处在雷达要捕捉的「统一职位名形成前」阶段。

## 反证与失效条件

- 证据集中在腾讯、美团两家有自研大模型的平台公司，可能只是大厂内部分工，不代表中小公司或传统行业会单设这个岗位。
- 海外没有同名岗位，相关工作多由评测工程师或产品经理兼任；这可能是国内特有的岗位切分方式。
- 失效条件：若 8 周内（至 2026-12-07）没有第三家独立雇主出现，且这些岗位关闭后不再补招，回退 forming；若工作被并入通用 AI 产品经理或评测工程岗位，按 cooling 处理。

## 对良

- 适配不变（direct）：职责与良的临床评测、知识质控和验证型工作流同构。
- 最现实的入口是 LongCat 这类 1 年经验门槛、欢迎转岗的岗位，以及各家的评测类实习；3 年以上的岗位作中期目标。
- 作品建议：拿一个 Coding 或办公 Agent 做 20—30 个长程任务的评测集，配 Rubric、失败归因表和一次 A/B 对比。医疗方向可参考腾讯混元数据策略岗提到的医疗垂类后训练数据与评测。
