# AI 新职业雷达

## 一句话定义

监测 AI 带来的新任务何时开始被多家公司稳定采购，并在统一职位名形成前发现可进入的职业机会。

## 与现有项目的关系

- [[../AI求职系统|AI求职系统]]：维护良的真实背景、材料和具体申请流程。
- BossHunter：发现和处理具体招聘岗位。
- AI 新职业雷达：研究职业簇、需求阶段和能力迁移方向。
- [[../后台雷达|哨塔总控台]]：展示雷达摘要、内嵌版本和独立站启停入口，不混用 BossHunter 数据与控制权限。

- 已建立证据口径、目录规则和安全边界。
- 初版 [[reports/2026-08-29-第1期|第一期人工研究版]] 保留为历史；因把“对良适配”误作雷达排序，已由 [[reports/2026-08-29-第1期-v2-前沿修正版|第 1 期 v2 前沿修正版]] 纠偏。

- 已同步 `site/` 本地网站和本机 [[../后台雷达|哨塔总控台]]：同一证据快照提供“市场前沿版”和“良的适配版”。前者按新颖度与扩散排序，后者按良的可进入性排序。
- 哨塔可以在固定回环地址 `127.0.0.1:3001` 启停独立站；不注册开机自启，不提供任意路径、端口或命令输入。

- 网站当前读取第一期人工研究快照，不是实时招聘流；定时任务和公开部署仍未建立，也未获得授权。

## 第一阶段验收（已完成）

第一期应交付：

- 8—12 个职业簇；
- 每项的制度状态、需求阶段、置信度和良的匹配度；
- 事实、推断、反证与失效条件；
- 直接可执行的“现在 / 触发后 / 暂不做”建议；
- 可点击且日期明确的主要来源。

第一期完成后再判断是否值得连续周更；至少经过数期真实增删和纠错后，才讨论评分模型与网站自动化。

## 本地网站原型

- 源码：`site/`
- 数据快照：`site/lib/radar-data.ts`
- 哨塔展示镜像：由本机哨塔项目维护，不进入本仓库。
- 页面主体：`site/components/radar-page.tsx`
- 当前本地预览：从哨塔总览打开“开启独立站”，固定使用 `http://127.0.0.1:3001/`；端口被其他进程占用时拒绝启动。
- 研究更新顺序：点击刷新得到候选状态 → 人工核验并更新信源登记、报告和观察池 → 同步网站数据快照与哨塔镜像 → 执行类型、静态和生产构建验证。

2026-08-29 验证结果：本站源码 lint 通过、TypeScript 检查通过、`vinext build` 通过、本地页面返回 HTTP 200。全量 `pnpm lint` 仍会命中脚手架自带但未使用的 shadcn 组件规则冲突；没有为过检查而修改这些无关组件。

2026-08-29 双版本与本机刷新验证：`site/lib/radar-data.ts` 与哨塔镜像逐字一致；本站 TypeScript、改动文件定向 oxlint、生产构建与本地 HTTP 200 通过。哨塔严格 TypeScript、ESLint、生产构建与 9/9 自动测试通过。真实启停验证确认 3001 可启动并释放；固定信源刷新本次 5 个来源中 3 个可达，OpenAI 两个搜索页返回 HTTP 403 并被如实记录为失败。全量本站 oxlint 仍只命中未使用脚手架组件的既有问题。

源码已获授权同步到私有 GitHub 仓库。公开 URL、域名、访问控制、定时更新频率和运行成本尚未决定；公开部署或把仓库改为公开仍需良单独授权。
