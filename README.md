# AI 新职业雷达

## 一句话定义

监测 AI 带来的新任务何时开始被多家公司稳定采购，并在统一职位名形成前发现可进入的职业机会。

## 与现有项目的关系

- [[../AI求职系统|AI求职系统]]：维护良的真实背景、材料和具体申请流程。
- BossHunter：发现和处理具体招聘岗位。
- AI 新职业雷达：研究职业簇、需求阶段和能力迁移方向。
- [[../后台雷达|哨塔总控台]]：只负责启停并打开独立站，不复制职业数据或两个版本。

## 第一阶段验收（已完成）

第一期应交付：

- 8—12 个职业簇；
- 每项的制度状态、需求阶段、置信度和良的匹配度；
- 事实、推断、反证与失效条件；
- 直接可执行的“现在 / 触发后 / 暂不做”建议；
- 可点击且日期明确的主要来源。

第一期完成后再判断是否值得连续周更；至少经过数期真实增删和纠错后，才讨论评分模型与网站自动化。
