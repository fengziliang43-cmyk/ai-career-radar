# AI 新职业雷达

## 一句话定义

监测 AI 带来的新任务何时开始被多家公司稳定采购，并在统一职位名形成前发现可进入的职业机会。

## 与现有项目的关系

- [[../AI求职系统|AI求职系统]]：维护良的真实背景、材料和具体申请流程。
- BossHunter：发现和处理具体招聘岗位。
- AI 新职业雷达：研究职业簇、需求阶段和能力迁移方向。
- [[../后台雷达|哨塔总控台]]：只负责启停并打开独立站，不复制职业数据或两个版本。

## 第一阶段验收（已完成）

第一期应交付：

- 8—12 个职业簇；
- 每项的制度状态、需求阶段、置信度和良的匹配度；
- 事实、推断、反证与失效条件；
- 直接可执行的“现在 / 触发后 / 暂不做”建议；
- 可点击且日期明确的主要来源。

第一期完成后再判断是否值得连续周更；至少经过数期真实增删和纠错后，才讨论评分模型与网站自动化。

## 本地网站原型

- 源码：`site/`
- 数据快照：`site/lib/radar-data.ts`
- 哨塔不保存展示镜像，只读取独立站有限运行状态。
- 页面主体：`site/components/radar-page.tsx`
- 当前本地预览：从哨塔总览打开“开启独立站”，固定使用 `http://127.0.0.1:3001/`；端口被其他进程占用时拒绝启动。
- 自动发现：读取公开职位 → 去重与任务归并 → 保存本地发现状态 → 更新默认首页；研究档案更新：人工核验 → 信源登记、报告和观察池 → 同步静态快照 → 构建验证。发现逻辑见 `site/lib/radar-discovery.ts`，展示见 `site/components/discovery-board.tsx`。

2026-08-29 验证结果：本站源码 lint 通过、TypeScript 检查通过、`vinext build` 通过、本地页面返回 HTTP 200。全量 `pnpm lint` 仍会命中脚手架自带但未使用的 shadcn 组件规则冲突；没有为过检查而修改这些无关组件。

2026-08-29 双版本与本机刷新验证：本站 TypeScript、改动文件定向 oxlint、生产构建与本地 HTTP 200 通过。哨塔只保留启动卡片，不再导入或展示职业数据。真实启停验证确认 3001 可启动并释放；固定信源刷新本次 5 个来源中 3 个可达，OpenAI 两个搜索页返回 HTTP 403 并被如实记录为失败。全量本站 oxlint 仍只命中未使用脚手架组件的既有问题。

2026-08-31 应聘知识验证：13/13 个职业簇均有 `requiredKnowledge`，共 53 个知识领域，每项 4—5 个；知识内容已进入搜索索引。定向 oxlint、严格 TypeScript、格式检查、生产构建与本地 HTTP 200 通过。

源码已获授权发布到公开 GitHub 仓库：[fengziliang43-cmyk/ai-career-radar](https://github.com/fengziliang43-cmyk/ai-career-radar)。公开前已检查当前两次提交，未发现密钥、联系方式、用户绝对路径或患者资料；提交邮箱使用 GitHub `noreply` 地址。仓库公开只代表源码、研究文档和提交历史可见，本机入口仍可使用；2026-10-11 已部署上述私有服务器入口。本轮没有 push，也未开放匿名访问或增加域名。
